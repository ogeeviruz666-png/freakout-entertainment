## Your only task is transferring the files

1. Download and extract the ZIP.
2. Open your GitHub repository at the main/root level.
3. Upload every item from inside the extracted folder.
4. Replace older files when prompted.
5. Commit with: `Launch Freak Out Entertainment V6.0 Signature Edition`
6. Wait 1–3 minutes for GitHub Pages to rebuild.
